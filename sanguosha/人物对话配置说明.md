# 三国杀人物头像与气泡配置

打开一局三国杀后自动生成 `BepInEx/config/studio.studentage.sanguosha-dialogue.json`。关闭牌桌后修改，下次开局读取；更新插件不会覆盖此配置。配置损坏时保留原文件并使用默认内容，日志记录原因。

右上方显示当前对战的《学生时代》角色；左下方显示存档主角，按男女、学段和服装读取原游戏头像。F7测试演示默认用中学女主，不修改存档。头像与武将牌是不同人物。

默认只有真正出杀、出闪时出现“杀！”“闪！”，与展示中的出牌事件同步；其他牌不自动说话。气泡随文本宽度变化，长句换行，不说话时完全隐藏，暂停/规则查看期间停止计时。气泡沿用三国杀原始棕金背景和暖白色书法字体，尾巴对准头像中心，与气泡合为一体避免接缝。默认2.2秒，带短淡入淡出。

## 配置字段

- `Schema`：固定1。
- `Enabled`：是否显示人物头像和气泡，默认true。
- `MaxBubbleWidth`：气泡最大宽度，默认300，允许150～360（1600×900逻辑画布）。
- `Lines`：全局台词。`slash`为杀，`jink`为闪。每条包含`Text`文字、`Expression`表情名称、`Seconds`时长（0.8～15秒）。空文字不显示。
- `Speakers`：人物独立设置。`player_female`为女主，`player_male`为男主；其他键为人物ID：3梁超杰、101罗晓纯、102薛诗蕾、103陈心慈、104谭梓君、105肖清雅、201孟怀安、202林嘉宇、203程良、204谢辰晖。
- 各人物的`Lines`：覆盖该人物的同名全局台词，其他台词继续使用全局配置。
- 各人物的`Expressions`：表情图。默认提供`neutral`（不说话）、`slash`、`jink`三个位置，也可以另加名称，每人最多预加载32种。
- 表情的`Image`：空字符串使用原游戏头像。可填PNG/JPG绝对路径、相对于BepInEx/config的路径（如`sanguosha-faces/201-angry.png`），或`native:role_head/role_female2_xiaofu`这种原游戏资源路径。图片不随插件重新分发，实际运行时读取。
- 表情的`FaceId`：默认-1；没有指定Image时，可填ModFaceCfg中该人物、当前服装对应的表情编号。没找到时回退原头像。原版头像本身是静态图，想显示另外的神态需要配置相应图片或已有Mod表情；不会凭空变出表情画作。
- `Zoom`：头像裁切放大倍率，1～4。
- `CenterX`、`CenterY`：裁切中心，0～1，Y从图片底部向上。默认均0.5。

## 示例：给孟怀安配置杀的台词和表情

在`Speakers`的`201`条目中保留其他字段并填写：

```json
{
  "Expressions": {
    "neutral": { "Image": "", "FaceId": -1, "Zoom": 1, "CenterX": 0.5, "CenterY": 0.5 },
    "confident": { "Image": "sanguosha-faces/201-confident.png", "FaceId": -1, "Zoom": 1.1, "CenterX": 0.5, "CenterY": 0.55 }
  },
  "Lines": {
    "slash": { "Text": "杀！", "Expression": "confident", "Seconds": 2.2 }
  }
}
```

示例图片需自行放入对应目录。未配置或未加载的说话表情会使用neutral；没说话恢复neutral。图片异步加载，关闭牌桌后不会把旧人物加载到新局，临时圆形纹理随牌桌关闭销毁。

后续剧情可加入任意台词键，再由代码调用`SanguoshaView.Current.SpeakParticipant(0, "台词键")`或`SpeakParticipant(1, "台词键")`，0主角、1对手。本次只接杀/闪自动触发，没有编造长篇人物对话。一次显示最多240字符、7行，超出可见行数显示省略号，建议把长篇对白拆为多条。
