# 三国杀第一关剧情（胜利与失败）

读档后从角色社交入口进行正式对局，主角在该角色第一关结束时：

- 获胜：胜利动画 → 新武将解锁动画（获得新卡时）→ 点击确定/返回 → 原游戏剧情界面播放该角色的“胜利”剧情。
- 失败（含认输）：失败圆徽 → 点击返回 → 原游戏剧情界面播放该角色的“失败”剧情。武魂同归于尽的和局不算失败，不播放。

对白、人物入场、朝向、表情差分和条件分支沿用提供的配置。十位角色（梁超杰、罗晓纯、薛诗蕾、陈心慈、谭梓君、肖清雅、孟怀安、林嘉宇、程良、谢辰晖）胜利、失败各一段，共二十段；林嘉宇两段已补齐。

每段剧情按原配置 maxcount=1 只播放一次，已播记录写入原生存档中的三国杀进度（`Stories`）。已看过失败剧情后再次在第一关被击败不重复播放；之后赢下第一关仍会播放胜利剧情。第二/三关和标题页 F7 临时测试对局不播放这些剧情。已通关第一关的旧进度不自动补播。

剧情不会再次发放关卡奖励武将卡或好感；对局结算仍按原规则执行。林嘉宇的失败剧情中，他递出的武将卡通过对白效果 `[60,1,920006]` 发放物品“郭嘉·武将卡”（插件注册的三国杀物品，已持有时不重复）。陈心慈的条件 320907、梁超杰的男女主称呼分支均保留；孟怀安先只接入尚未赢过他的版本。

## 配置位置与编号

插件内：`Sanguosha/Stories/FirstWin/{TalkCfg,OptionCfg,EvtCfg}.json`。三份文件保留原对白和表情，仅按要求删除孟怀安尚不启用的分支，共 148 条对白、22 条选项、20 条事件；事件 1222100–1222109 为胜利、1222110–1222119 为失败，按 EvtCfg.npc 绑定人物。

载入时在内存中将本批对白编号加 700000000、选项编号加 70000000、事件编号加 700000，并同步内部跳转。对白/选项/事件里“已触发剧情/已选择选项/已到达对话”条件（类型 3）若指向本批编号，同样按上述偏移转换；其他外部条件（320907、性别）和人物编号保持原值。事件统一注册为专用类型 920092，避免混进原生随机事件池。遇到其他 Mod 占用且内容不同的编号时记录错误，不覆盖对方数据。

后续第二、三关需要单独接入，目前只绑定第一关。修改文件后重启游戏生效。

## Mod 作者：绑定自己的角色剧情（0.11.1）

玩家启用本工坊整合版与你的角色 Mod 后，即可共用小游戏 DLL。不要复制或覆盖本插件的 FirstWin 文件。

在自己的 Mod 的 `Cfgs/zh-cn/EvtCfg.json` 中新增完整事件行：`npc` 填自己角色 ID；第一关胜利事件 `type=920093`，第一关失败事件 `type=920094`，`talkId` 指向自己 Mod 的对白。事件和对白使用自己独立的编号。配套 `TalkCfg.json`、`OptionCfg.json` 仍按原游戏格式提供，人物表情、入场、朝向、条件分支由原生剧情系统演出。可以用「拾光工坊模组编辑器」编辑这些配置。

每个角色每种结果绑定一条事件。这两种专用类型不会加入原生随机剧情池；多个 Mod 重复绑定同一角色/结果时，使用最小事件 ID 并记录警告。作者绑定优先于本插件自带剧情。作者事件 ID 不做偏移，保留原生跨事件条件引用；剧情按自己的事件 ID 记录已播放状态。禁用角色 Mod 后，其配置不再载入，绑定随之消失。

当前仅支持第一关胜利、失败；失败包括认输，不包括和局。第二、三关剧情尚未接入。首次结果点击收下/返回后进入原生对白，F7 标题测试对局不触发存档剧情。角色仍需通过原游戏的社交系统出现，购买三国杀后由本插件添加对战选项。
