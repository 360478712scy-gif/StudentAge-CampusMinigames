# 三国杀 · 社交集卡

2003年起，小卖铺出售10元一盒的三国杀。购入即持有，心情每回合增加3点，并得到初始武将赵云。小卖铺上方的“三国杀”分类出售其余武将，普通武将20元，神关羽和神吕蒙各100元。

拥有三国杀后，在原游戏人物社交界面选择“打三国杀”。每游戏回合最多对战一局；输赢均获得10好感。只有胜利才推进关卡并获得对方的武将卡，失败只能下回合重试。每个角色三关，全部获胜后关闭该角色入口。收藏和对战进度随原生存档保存。

- 简单模式：双方摸牌阶段基础摸3张，出牌阶段基础限出2张杀，体力上限加1。
- 复杂模式：双方摸牌阶段基础摸2张，出牌阶段基础限出1张杀，原始体力。
- 两种模式均为一对一，标准108张牌（含EX），开局各4张手牌。
- 使用旧标准25将、旧风8将，以及神关羽、神吕蒙的技能。武将技能、武器特效可改变基础规则。
- 一对一没有主公身份和第三方目标，主公技不启用；貂蝉的离间、大乔的流离没有合法的第三方目标，仍保留其余技能。武魂导致双方同时阵亡时按和局处理，不推进关卡，仍增加好感。
- 点击手牌或下方选项进行操作；转换牌会提供技能用法。点击武将卡可放大并查看技能。Esc暂停，可继续或认输。
- 从持有物品对应的“三国杀卡册”行动可浏览全部35张武将。

详见[角色武将分配](角色武将分配.md)。男线限定角色和女线限定角色共享相应奖励卡范围；没有对应DLC时，无法取得的DLC角色卡转为商店出售。第三方新增可社交NPC使用固定的公共奖励组合，避免出现路线独占卡。
