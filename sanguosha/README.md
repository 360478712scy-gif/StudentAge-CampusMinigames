# 三国杀 · 社交集卡

2006年年初起，小卖铺出售10元一盒的三国杀。购入即持有，心情每回合增加3点，并得到初始武将赵云。小卖铺上方的“三国杀”分类出售其余武将，普通武将20元，神关羽和神吕蒙各100元。

拥有三国杀后，在原游戏人物社交界面选择“打三国杀”。每游戏回合最多对战一局；输赢均获得10好感。只有胜利才推进关卡并获得对方的武将卡，失败只能下回合重试。每个角色三关，全部获胜后关闭该角色入口。收藏和对战进度随原生存档保存。

- 简单模式：双方摸牌阶段基础摸3张，出牌阶段基础限出2张杀，体力上限加1。
- 复杂模式：双方摸牌阶段基础摸2张，出牌阶段基础限出1张杀，原始体力。
- 两种模式均为一对一，严格使用官方公布的52张单挑牌组，开局各4张手牌。
- 使用旧标准25将、旧风8将，以及神关羽、神吕蒙的技能。武将技能、武器特效可改变基础规则。
- 一对一没有主公身份和第三方目标，主公技不启用；貂蝉的离间、大乔的流离没有合法的第三方目标，仍保留其余技能。武魂导致双方同时阵亡时按和局处理，不推进关卡，仍增加好感。
- 长按手牌拖出目标箭头：杀与单体锦囊拖向对手；桃、装备、无中生有拖向自己；南蛮、万箭拖至场中。闪或无懈拖到正在结算的那张牌上，可继续反无懈。空处松手、拖回手牌或右键取消均不耗牌；单击不选牌、不出牌。右侧保留“结束回合”，需要响应时该位置变为“不出”；真实选牌环节直接点击所需牌。转换与主动技能位于自己武将下方，右键查看手牌或武将，Esc暂停。
- 体力降至0或以下时立刻进入自救，没有可用自救手段或放弃救援即刻阵亡，不等回合结束。牌组无酒，也不能通过蛊惑声明酒。
- 乐不思蜀显示“乐”，非红桃判定跳过出牌阶段，仍然摸牌和弃牌。兵粮寸断显示“兵”，非梅花判定跳过摸牌阶段。水淹七军让对手弃置全部装备或受1点伤害，无装备时自动受伤。
- 判定流程：公开翻出判定牌，允许鬼道/鬼才拖牌改判，随后展示最终牌和原版判定生效/失效动画及具体结果。鬼道支持黑色手牌和装备，鬼才仅支持手牌；拖错区域不耗牌。
- 闪直接拖到来牌上即可响应；即使装备八卦阵也不必先点发动。八卦阵是旁边独立可选项，判黑后仍可出闪。涉及手牌消耗的技能可将牌拖入场中，仁德拖向对手；真正的选牌与选择效果仍保留对应选择。
- 顺手牵羊与过河拆桥可选择对手的明置装备、判定牌，或随机抽取一张手牌，点击即结算。顺手获得的牌收入手牌，不自动装备；过拆公开展示弃牌，不能拆自己。只有手牌时直接随机抽取，不额外弹窗。
- 牌组参照[官方单挑牌表](https://www.sanguosha.cn/pc/guide-info-37.html)，移除坐骑、方天画戟、麒麟弓、雌雄双股剑、青龙偃月刀、借刀杀人、五谷丰登、桃园结义与闪电；武将仍使用上述标风版本，非完整移植三将轮换模式。
- 军争篇按此单挑牌表取舍：保留梅花Q兵粮寸断，不额外添加酒、火杀、雷杀、火攻、铁索及军争装备。南蛮、万箭在官方单挑牌表中各1张，因此仍保留。
- 开局只洗一次固定牌堆，随后从牌堆顶依次摸牌；摸空时只回收已结算的弃牌并洗牌。手牌、装备、判定区、不屈牌和正在结算的牌不混回。无牌可回收时停止摸牌，不凭空补牌。
- 从持有物品对应的“三国杀卡册”行动可浏览全部35张武将。

详见[角色武将分配](角色武将分配.md)。十位角色各三张奖励、共三十张不重复；孙权为孟怀安第三关。当前性别路线不存在的角色、未购买DLC的角色，其卡牌均转到商店，各20元。两条路线都能收齐35将；旧存档已通关阶段新分配的缺失卡也可补买。

程序规则为本项目独立实现。画面与声音使用QSanguosha-v2，以及decadeUI、noname中收录的三国杀资源和十周年公开客户端原始图集、动画、界面字体；具体来源、版本、哈希及随附声明位于Sanguosha/sources.json、Sanguosha/decade/sources.json、Sanguosha/hd/sources.json、Sanguosha/official/sources.json、Sanguosha/audio-additions-sources.json与随附LICENSE等文件。保留原作者和权利人的署名，不将原版美术、声音宣称为本项目原创。

牌桌布局参考 Steam《三国杀》（App 1180320）的实机对战：中央公共出牌区、底部手牌、右下方己方武将与技能、相邻装备区。武将侧边显示阴阳玉体力槽，按残血变色，超过5点体力改为数字；用户选定的decadeUI彩色牌面使用原生400×555资源，点数花色按原尺寸合成；手牌通过透视网格呈现，随指针轻微俯仰、转动，悬停抬起并让相邻手牌平滑让位；中央出牌与响应平滑补位。体力、阵营、装备、按钮、书法字体及杀/闪、红黄光框取自原始图集与动画，由Unity实时播放。龙纹底图尚未与参考视频完全一致。当前作为 0.11.0 GitHub 试玩版发布，适用官方 1.94。

人物社交入口左侧为原标志繁体“殺”圆印。已接入35将阵亡语音、技能与转化技台词、男女出牌配音和装备/落牌/受伤/恢复声音。声音随Esc暂停并续播；胜负结算不再截断最后一击和阵亡声音。正常击败对手后，先播完“一破·卧龙出山”，再播放原版胜利动画和胜利音，随后播放原版招募金光和新武将卡亮相，点击“确定”收起牌桌；认输不会触发“一破”。不再显示好感＋10和获得武将的文字结算弹窗，奖励仍按原规则写入存档。失败停留原版失败圆徽并提供返回按钮。背景音乐淡出，在收起牌桌后恢复。

选牌、技能选择和详情窗口使用十周年原始柔边底图，移除自绘黑色硬边框。胜负文字按完整画布定位，首帧按实际时点播放；一破、胜负和新卡过渡保留同一层暗幕。手牌从发牌位置进入真实手牌槽，出牌保留到公开牌起飞，旧公开牌从原位置退场。

关注的新同学达到 5 人时，未关注同学对应的武将卡也进入商店，普通武将 20 元。商店按当前关注状态计算，已拥有卡牌不重复出售；未满 5 人时恢复原有售卖范围。三国杀盒子的描述为“你杀不过我你信吗？”。

人物头像位于右上（当前对手）和左下（实际主角）。杀/闪显示短暂气泡，其他牌不说话。台词、表情图片、时长可编辑，见[人物对话配置说明](人物对话配置说明.md)。

各角色第一关正式对局结束后播放原生剧情：获胜收下武将卡后播放胜利剧情，失败（含认输）点返回后播放失败剧情（和局不播），保留表情差分与分支，每段只播一次。十位角色胜负各一段已接齐，林嘉宇失败剧情会送出郭嘉武将卡，详见[第一关剧情说明](第一关胜利剧情说明.md)。

对手装备以完整牌面显示在武将左侧，右键可放大查看；拆桥及水淹七军逐张展示移出和弃置的牌。八卦阵双方均公开翻出实际判定牌，再显示生效/失效；红色视为出闪，黑色不产生闪。双方基础摸牌数一致（简单3、复杂2），摸牌动画跟随实际数量，技能增减仍按规则处理。
