# 学生时代小游戏 · UP 接入包

需要 Windows x64 / Unity Mono / BepInEx 5，以及提供 Begin、Cancel、Invalidated 和插件目录注册支持的 UP 1.0.23 或更新兼容版。合并版与 split 版二选一；本包不附 UP、BepInEx 加载器或游戏程序集。

退出游戏后，将包内 BepInEx 合并到游戏根目录。CampusUno/CampusUno.dll 替换旧版同路径文件，不能同时保留另一份旧 CampusUno.dll。已有 BepInEx/config/BepInEx.cfg 中 HideManagerGameObject 必须为 true。

- CampusUno：UNO 现有四人对局与视觉界面，检测 UP 时交出旧社交拦截和结算。
- StudentAgeCampusMinigames：公开 UP 适配器、注册 JSON、默认阶段 CFG、CC0 音效；包含附加小游戏的原生 Unity 玩法及共享扑克资源。
- 默认元数据只在游戏内存中补缺失项，不覆盖作者 Mod 配置，不修改游戏数据文件。
- ModAuthorTemplate 是作者参考，不是应放到游戏根目录的可自动发现 Mod。UP 不会把任意根目录 Mod 文件夹当作原生角色 Mod。

## 绑定模组角色

在角色作者现有、已经启用的 Mod 中，保留完整 PersonGrowCfg 行，仅把该角色 minigame 设为下表对应编号。原版一个角色只有一个此类绑定，不自动合并为多个小游戏菜单。本包不擅自改绑任何原版或用户角色。

作者如需覆盖关卡费用/关系/开场和胜负剧情，把模板 Cfgs/zh-cn 中相应完整行合并进自己的 Mod。不要把示例文件整体覆盖已有配置。注册 JSON 与 DLL、Audio 已由插件本地目录提供，通常不要在角色 Mod 再复制一份注册，避免重复 ID。

UNO 默认五个社交阶段，均调用现有四人 UNO 玩法；五子棋阶段 910201–910205、课间泡泡阶段 910301–910305 对应内部难度 1–5。开局前只有开始和说明，局内不提供难度、先后手或选关按钮，五子棋固定玩家黑先。过关推进属于各 NPC 的 UP 状态；失败/和棋不推进，五关完成沿用原版小游戏完成状态。

准备页不扣费，开始时由 UP 扣费一次。胜负分出后使用原版小游戏结果提示，提示结束后由 UP 推进阶段并按原版执行效果和胜利基础好感。小游戏自身不重复发奖励。宿主失效会关闭界面和恢复输入；中途因读档等强制取消不伪造胜负。

课间泡泡：方向键 / WASD 移动，空格放泡泡，也支持按住屏幕方向键和点击放泡泡。课桌挡水波，纸箱/书包可冲开；圆点为剩余机会，耗尽后结束。第一关对手 1 次机会，之后 2 次；五关反应速度和能力在内部配置，玩家不能选关。

## 音乐与音效

UNO、五子棋和课间泡泡默认引用原版小游戏 BGM（AudioCfg 8，与数独/翻牌一致）。进入准备页即使用游戏原有音乐通道循环播放，退出后调用原版 BGM 恢复逻辑；角色作者提供的 MinigameCfg.bgm 优先，0 保持当前音乐，-1 暂停音乐。

小游戏不再放置独立音效开关。音效默认播放，已接入原游戏 SoundMixer 和静音状态，音量由游戏设置统一控制。音乐文件从游戏安装读取，不随插件复制。

## 验证边界

详见 docs/UP_INTEGRATION_HANDOFF.md。只在隔离游戏、重定向存档与内存 NPC 配置上验证；不将定向联调视为真实用户 Mod、自然周目或 Windows 原生完整验收。

## NDS掌机（0.8.0本地预览）

2005年夏季起，小卖铺出售「NDS掌机」，100元、限购一台，买后解锁同名2类行动。像素双屏菜单可选择12款拓展小游戏，所有游戏共用每回合3关新通关额度（马里奥每关算0.5）、已通关关卡不限重玩；掌机关卡与角色社交进度分开，一局结束回到掌机。开机动画后进入菜单，左上角返回校园。持有掌机每回合智力、情商、体魄、心情各+5，不占珍藏位。购买和关卡信息保存在原游戏存档。升级额外保留Nds资源目录；细节见《NDS掌机说明.md》。

## 调整小游戏参数

启动一次后编辑 `BepInEx/config/studio.studentage.minigames.cfg`；140项设置均有中文注释，覆盖12款游戏。修改后重启。完整默认示例在“配置示例”，参数用途、范围和恢复方法见《小游戏配置说明.md》。保留你已有的cfg，不需要用示例覆盖。

UNO单独的F10入口已移除，旧EnableF10配置项会在启动时清理。通过掌机或角色社交进入UNO即可。
