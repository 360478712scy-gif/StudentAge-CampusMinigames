# Third-party notices

The full Windows bundle includes BepInEx 5.4.23.5, HarmonyX, MonoMod, Mono.Cecil, and UnityDoorstop 4.5.0. Their license texts are provided in `licenses/` and in the release archive's `第三方许可/` directory. The dependency archive was downloaded from the official BepInEx release and checked against its published SHA256.

- BepInEx: https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
- HarmonyX: https://github.com/BepInEx/HarmonyX
- MonoMod: https://github.com/MonoMod/MonoMod
- Mono.Cecil: https://github.com/jbevain/cecil
- UnityDoorstop: https://github.com/NeighTools/UnityDoorstop/tree/v4.5.0

The UNO-inspired one-minute rules are an original accelerated implementation. Card graphics are generated by this plugin's Unity UI code; no official UNO card graphics or logo are included. The plugin uses the game's installed font at runtime. The release contains no game assets, game DLLs, decompiled game source, or player saves.

## 0.6.0 Landlord, Snake and campus maze

Landlord rule research: DouZero (Apache-2.0), https://github.com/kwai/DouZero and the standard game description https://www.pagat.com/climbing/doudizhu.html . Research source snapshots and their license are retained locally in research/second-trio. The release uses its own C# classifier, legal-move generation and heuristic opponent, not DouZero's Python implementation, trained model or network service. No research source or model is shipped.

Landlord reuses the same CC0 traditional faces and original campus back as 24. Arcade SVG/PNG illustrations (snake, candy, pupil and patrol) are original project vector art. The maze layout and movement/chase logic are project code. No official Pac-Man sprite, logo or sound is included. Effects reuse the recorded audio credited above; no synthesized oscillator effects were added.

0.6.0 card rendering modifications: supersampled 420×588 images include transparent gutters, a softened outline and readable Joker corner letters; 400×560 remains the printed area. The supplied CC0 license and original sources remain included.
