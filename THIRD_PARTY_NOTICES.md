The full Windows bundle includes BepInEx 5.4.23.5, HarmonyX, MonoMod, Mono.Cecil, and UnityDoorstop 4.5.0. Their license texts are provided in `licenses/` and in the release archive's `第三方许可/` directory. The dependency archive was downloaded from the official BepInEx release and checked against its published SHA256.

- BepInEx: https://github.com/BepInEx/BepInEx/releases/tag/v5.4.23.5
- HarmonyX: https://github.com/BepInEx/HarmonyX
- MonoMod: https://github.com/MonoMod/MonoMod
- Mono.Cecil: https://github.com/jbevain/cecil
- UnityDoorstop: https://github.com/NeighTools/UnityDoorstop/tree/v4.5.0

The UNO-inspired one-minute rules are an original accelerated implementation. Card graphics are generated by this plugin's Unity UI code; no official UNO card graphics or logo are included. The plugin uses the game's installed font at runtime. The release contains no game assets, game DLLs, decompiled game source, or player saves.
