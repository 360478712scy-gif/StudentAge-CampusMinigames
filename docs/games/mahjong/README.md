# 课间麻将 · 0.7.1 本地预览

四人简化日常麻将，玩家与社交角色、两名路人同学同桌。牌面为传统万条筒与字牌，桌面改为暖木框、墨绿绒面的麻将桌；姓名、头像、按钮和开始前说明沿用学生时代。

## 规则与操作

- 136张牌，无花牌、无百搭；玩家坐东先手。每次社交只打一局。
- 四组顺子/刻子加一对将，或七种不同对子，即可胡牌；四张相同不拆成两个七对对子。不设番数门槛或下注。
- 只吃上家；任意一家可碰、明杠或胡。胡优先，其次碰杠，再次吃；多人同时胡取出牌者之后最近的一家。
- 支持暗杠、补杠和抢补杠胡，杠从牌尾补牌；牌墙用尽流局。
- 点击手牌选中，再点“出牌”或再次点击同一张。提示只选牌，不自动打牌。可响应时显示吃、碰、杠、胡、过。
- 玩家先胡为社交胜利；其他玩家先胡或流局不算胜利。没有局内返回、倒计时、选关或音效开关。
- 五个内部社交阶段调整电脑选牌策略。电脑只用自己的手牌和公开信息，不读取其他人的暗牌。

## 画面实现

所有麻将使用同一实体尺寸。牌体有真实圆角、平滑法线和表面材质，由独立Unity相机绘制到3200×1800、4倍MSAA的透明画面，再放回原有UGUI牌桌。深度缓冲负责整排牌的遮挡，避免按UI排序出现白块与断面。桌面只有接触阴影，没有镜面倒影。牌面纹理使用mipmap和各向异性过滤。

局内主体不用额外网页内核。绘制资源在插件的Mahjong目录；只需随插件保留牌面、桌面等图片；牌体复用宿主自带材质，无需附加材质包或安装Unity编辑器。

## 入口与文件

角色绑定 minigame=9112，五阶段911201..911205，费用、阶段和结果仍由UP持有。

- 规则：src/Games/Mahjong/MahjongGame.cs。
- 场景与牌体：src/Games/Mahjong/RoundedMahjongScene.cs、MahjongProjection.cs、MahjongTileView.cs。
- 原版界面与动画：src/Games/Mahjong/MahjongView.cs。
- 原创桌面和牌面绘制：mahjong/tools/make_art.py。牌面字体用本机Songti SC Bold绘制，不附字体文件。
- 渲染材质：运行时读取宿主 Legacy Shaders/Diffuse 与 UI/Default；灯光仅作用于麻将层。
- 本地构建：dist/up-integration-0.7.1-preview。

## 验证范围

规则检查覆盖250局完整电脑对局、136张实体牌守恒、有效胡型、吃碰杠胡优先级、暗杠补牌、抢杠胡和流局。宿主定向检查覆盖社交入口、准备说明、发牌、真实指针选牌、出牌、吃牌、临近胜利胡牌及释放输入。最终结果与构建指纹以qa/mahjong-0.7.1/verification.json为准。

宿主验证使用隔离游戏副本、测试存档和CrossOver；不能等同于Windows原生、真实用户角色Mod或五阶段人工难度验收。
