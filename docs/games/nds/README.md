# NDS掌机 · 0.9.4

2005年夏季起，在原游戏小卖铺的持有类商品中出售，默认100元（cfg可调），每个存档限购一台。购买后解锁「NDS掌机」行动，ActionCfg.type=2；购买物品、行动和各游戏关卡记录均由原游戏存档保存。掌机属于持有物品，不占装备或珍藏位；持有时每回合智力、情商、体魄和心情各+5，沿用原游戏属性上限及效果结算。购买、打开或关闭掌机不会额外加一次。

## 使用

在游戏启动后的标题主界面按F8，可直接打开掌机；无需读档或购买，12款游戏的59个现有阶段全部开放，完整对局后返回掌机。仅标题主界面响应此快捷键，存档内暂停菜单、其他界面或加载遮罩中无效。此入口不保存通关进度、不改变存档内掌机持有状态。

从2类行动点击「查看」，先播放约2.4秒双屏开机动画，再进入菜单。左上角「返回」可在菜单或开机时回到游戏。

双屏像素菜单：下屏两页共12张游戏卡带，上屏选择所选游戏的关卡。点击开始或掌机A键启动；完整一局结算后回到掌机。掌机菜单可以通过电源、B键或Esc收起；进入小游戏后保持原来的完整游戏画面；局内按Esc打开暂停菜单，可继续、重开或认输。马里奥与魂斗罗直接进入场景，对应像素图文操作说明位于暂停菜单。

可以用方向键选择游戏、Q/E切换关卡、Enter启动。从存档内行动打开时，每个小游戏从第一关开始，所有小游戏共用每回合3关的新通关额度，马里奥每关计0.5，其他每关计1；失败可在本回合重试。只要额度足够，同一游戏也可连续推进。已经通关解锁的关卡可以无限重玩，重玩不占新关名额。剩半关时仍可挑战马里奥新关，额度用完等下一回合。所有记录与当前存档绑定，与角色社交进度无关，不消耗信任、不发角色社交奖励。购买只按配置价格扣款一次；菜单和重玩没有额外费用。

九款原有游戏及麻将各提供五个阶段；马里奥提供精选八关；魂斗罗目前只有丛林第一关。UNO五个阶段复用当前玩法，不代表五种独立关卡。具体玩法仍以各小游戏开局前的说明为准。

## 安装

当前发布版本：0.9.4，支持后台下载、退出后安装更新。继续使用BepInEx5与兼容UP，把包内BepInEx合并到游戏根目录；保留CampusUno和StudentAgeCampusMinigames两个插件目录及全部资源，包括新增的Nds目录。无需Unity编辑器、浏览器组件或单独存档数据库。原有角色Mod位置和小游戏绑定保留。

仍是本地预览；其中经典游戏素材沿用此前本地参考范围，未作为公开发行包。

## 接入与源码

物品、商品、行动、功能入口各自使用919901。注册只补内存配置，购买走原游戏ShopMgr.Buy；商店列表和直接购买都检查上市日期、持有状态。界面按配置价格（默认100元）显示并结算，不随通胀或折扣变化。已有Mod配置不写回。

- NdsIntegration.cs：元数据、原版小卖铺、购买防护、2类行动入口、读档失效处理。
- NdsConsole.cs：双屏菜单、12款目录、关卡选择和独立掌机会话。
- NdsProgress.cs：使用原生CommonEvtMgr的命名空间记录标签保存通关阶段、共享额度及回合，不新增存档格式或全局进度。
- IGameSession.cs：小游戏共用会话接口。UpSession保持角色社交生命周期；NdsSession校验开始与结算，独立记录掌机关卡后返回菜单。
- 上述代码在src/Games/Sanguosha；像素美术与字形生成在tools/nds/make_art.py，产物assets/nds。
- 检查入口integration/NdsRuntimeQA.cs、NdsShopRuntimeQA.cs、NdsSessionRuntimeQA.cs。证据qa/nds-0.8.0/verification.json。

验证使用隔离CrossOver游戏副本及测试存档。目录启动和定向结算不等于12款游戏所有关卡人工通关；Windows原生与真实用户Mod仍需验收。

当前本地预览：菜单使用《宝可梦 红》宝可梦中心芯片音乐；外壳两侧十字键及ABXY与屏幕留空。横版游戏直接开始，Esc暂停内可看对应像素图文操作说明。

## 徽章收藏

掌机右上角打开收藏集：中央一枚大型“NDS大玩家”，外围十二枚不同造型的游戏徽章。点击任意徽章可放大欣赏，Esc返回收藏集；未解锁时显示黑影及像素问号。收藏墙与放大页面不显示属性栏，物品栏内可查看效果。

正式存档中完成某款小游戏的全部现有关卡，获得对应徽章并放入持有物品；旧存档已通关时，下次打开掌机会补发。首次获得时，游戏胜利结算后自动进入收藏墙：黑影浮起、像素锁扣碎开、徽章点亮，配合马里奥胜利音效后悬停展示。集齐十二枚后自动续播“NDS大玩家”解锁：外围徽章从原位移走，沿弧线汇聚并融入光芒，终极徽章渐显，金色长光条向屏幕四散。两种解锁都会停留展示，“收下徽章”只保留文字，点击页面任意位置后平滑返回收藏墙；不点击不会自动返回。收藏墙从第一帧保持不透明，不露出底下NDS菜单。领奖时NDS背景音乐约0.8秒渐弱至静音再暂停；普通胜利音在约0.55秒、终极马里奥城堡通关音在约0.75秒提前响起，没有额外上升音或冲击声。胜利音播完后仍保持背景音乐暂停，等全部奖励收下并返回后，约1.1秒从暂停处渐强续播。重复通关不重复获得或叠加效果。标题F8试玩不会发放或保存徽章。

## 可编辑配置

全部数值（速度、目标、生命、电脑策略、背景音乐音量、掌机共享额度与价格）都在 Mod 的 `Cfgs/zh-cn/` 下的 JSON 表里（`CampusMinigameCfg.json`、`SnakeCfg.json` 等），不再使用 BepInEx/config。把要改的表复制到自己 Mod 的 `Cfgs/zh-cn/` 里改，本 Mod 的表只是默认值。包内《小游戏配置说明.md》列出全部默认值、范围和修改方法。修改后重启生效，通关和徽章记录不会重置。
