# UI 与交互检索入口

## 原版 UI 与视觉例外
普通小游戏优先复用游戏纸张、字体、按钮、说明与结果界面。NDS 外壳采用双屏像素菜单；马里奥与魂斗罗保留经典像素、4:3 场景与对应暂停说明。判断 UI 必须看实际渲染和点击区域；源码可编译不能证明画面正确。

## 扑克牌与对手整排弧度
UNO 对手牌先重叠成一排再整体投影，保持弧度和透视，避免逐张随机侧转或抖动。传统扑克共用 54 张牌面与选牌组件；相邻牌阴影贴合透明圆角，不加外圈阴影。按钮位于手牌和飞牌上方且保持可见可点。详细尺寸与动画约定见 docs/design/牌桌约定.md。

## 姓名头像、剩余牌数与摸光洗牌
NativeSeatBadge 复用人物头像和牌数显示，头像从游戏读取，不重分发原版头像纹理。UNO 抽牌堆厚度对应真实余量；摸光保留弃牌顶牌及选定科目，其余洗回，不能凭空补牌。Reshuffle/DrawCountAfter 必须保留动画中间状态。代码在 src/Games/Uno/ 与 src/Common/。

## 暂停、音频与释放
Esc 暂停应同步冻结模拟、计时、AI、牌张动画和音频，恢复时状态一致；重开复用会话，不重复扣费。退出、读档、宿主失效需取消协程、回调和占用锁，恢复游戏输入/BGM。检查 NativeMinigameAudio、MinigamePause、UpSession；历史音轨和音量要求见详细设计，实际默认值查 CFG。

## 麻将与 NDS 徽章
麻将牌体要有厚度、统一物理尺寸和正确遮挡，绿绒木框与接触阴影，不做镜面倒影。NDS 徽章保持像素细节、锁定剪影、普通及终极解锁动画，领奖时菜单音乐淡出，全部领取后恢复；标题练习不能获得存档奖励。完整视觉要求见 docs/design/界面与玩法约定.md。
