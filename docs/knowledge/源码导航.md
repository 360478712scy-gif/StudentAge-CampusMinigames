# 当前源码导航

## 游戏规则与画面
所有游戏规则和画面统一放 src/Games/<游戏>/。Uno：UnoGame、UnoTable；Gomoku：GomokuEngine、GomokuView；Bubble：BubbleGame、BubbleView；Box、TwentyFour、Tetris、Landlord、Snake、Pacman 各有规则与 View。Retro 放 MarioGame、ContraGame、RetroData、RetroView、PixelCanvas；Mahjong 放规则、投影与牌体；Sanguosha 放规则、技能、桌面、社交和剧情。

## 共用 UI 与音频
src/Common/PlayingCards.cs、PlayingCardView.cs 是传统扑克；StandingCardProjection.cs 是整排立式手牌；NativeSeatBadge.cs 是姓名头像牌数；NativeCardTable.cs 是桌面；NativeSkin.cs 是原版皮肤；NativeMinigameAudio.cs 和 NativeMinigameResult.cs 管理音频与结果；PuzzleFrame.cs 是通用准备页。

## UP、生命周期、配置和更新
src/Core/Plugin.cs 是插件宿主；src/Integration/UpEntry.cs 含 UP 入口、UpLevel 与 UpSession，IGameSession.cs 是会话协议。src/Configuration/ 为 MinigameTables、MinigameTuning、ModCfgLocator；src/Update/ 为自动更新与安全安装事务。不要因历史 CampusUno 命名空间给它单独编译。

## NDS、进度与徽章
src/Handheld/NdsIntegration.cs 管购买和标题入口；NdsConsole.cs 管菜单与会话；NdsProgress.cs 管存档进度；NdsBadges.cs、NdsBadgeWall.cs、NdsBadgeUnlock.cs 管徽章与演出；MinigamePause.cs 管暂停。外壳/徽章/字体制作工具在 tools/nds/，资源在 assets/nds/。

## 测试、配置与打包工具
tests/<领域>/*.csproj 为独立规则或更新器测试。tests/Layout/test_packaging.py 检查单 DLL 工坊与手动包，tools/check_layout.py 检查路径/注册/清单。tests/Runtime/ 是旧版本宿主定向检查，不能直接当当前验证。mod/ 是默认 JSON，assets/ 是资源，tools/tuning/generate.py 与 tools/generate_stage_talks.py 生成表，tools/assemble_mod.py 组装。
