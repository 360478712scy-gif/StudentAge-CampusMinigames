# 小游戏项目现状

## 当前基线与贡献
当前仓库是 StudentAge-CampusMinigames。2026-09-19 核对的 Steam 工坊 3802190178 包为 0.12.0，适配《学生时代》1.94 测试分支。Fable 5.1 已完成单 DLL、JSON 表配置与剧情启动整合；后续目录整理承接这些成果。历史 GitHub 0.11.1 附件不能当成当前源码布局。

## UNO 与其他小游戏统一
UNO、五子棋、课间泡泡、换盒、24 点、俄罗斯方块、斗地主、贪吃蛇、吃豆人、马里奥、魂斗罗、麻将共用 CampusMinigames.dll 和 UP 注册，编号 9101–9112。三国杀另有同一 DLL 内的社交实现。UNO 不再有独立 DLL、目录、包或 F10 练习入口。旧命名空间/GUID 保留用于兼容，不能据此拆分插件。

## 当前内容与范围
NDS 提供十二款游戏与徽章；马里奥八关、魂斗罗当前一关，其余各五阶段，合计 59 阶段。NDS 标题 F8 练习不写存档；存档内仍走购买与进度机制。三国杀提供人物社交、武将收藏、阶段剧情与奖励。数值以 mod/Cfgs/zh-cn 和 tools/tuning/settings.json 为准，不从旧笔记抄写硬编码默认值。

## 现行知识与详细约定
本目录保存有效结论与源码入口。详细牌桌、徽章动画、像素菜单等用户要求保存在 docs/design/界面与玩法约定.md、docs/design/牌桌约定.md，它们是设计要求，不等于全部已验证。新问题先查当前代码与实际报告；不把旧 QA、旧模组或旧截图当成当前问题已复现的证据。
